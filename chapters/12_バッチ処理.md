# Chapter 12：バッチ処理

Chapter 12 は `backend/` のみ触ります。

この章では、定期的に自動実行する「バッチ処理」を実装します。図書館システムで必要な延滞ステータス更新バッチを例に、Djangoのカスタム管理コマンドの作り方を学びます。

## 12-1 バッチ処理の概念

### バッチ処理とは何か・なぜ必要か

Webアプリケーションのほとんどの処理は「ユーザーが操作したとき」に動きます。本を検索すれば検索結果が返り、貸出ボタンを押せば貸出が記録されます。

**バッチ処理**はこれとは異なり、「決まった時刻に自動で動く処理」です。ユーザーの操作を待たずに、スケジュール通りに定期実行されます。

たとえば図書館システムでは、返却期限を過ぎた貸出のステータスを `active` から `overdue`（延滞）に更新する処理が必要です。ユーザーが操作するたびに全件チェックするのは無駄で、毎日深夜に一括で確認・更新するのが自然です。

| 処理の種類 | タイミング | 例 |
|----------|---------|-----|
| オンライン処理 | ユーザーの操作のたびに | 本の検索・貸出・返却 |
| バッチ処理 | 決めたスケジュールで定期実行 | 延滞ステータスの更新・通知送信 |

### スケジュール実行の方法

バッチ処理を定期実行する方法は複数あります。本章ではバッチの実装（Djangoの管理コマンド）に集中します。

| 方法 | 概要 |
|------|------|
| **cron** | Linux の標準機能。サーバー上で実行時刻とコマンドを登録する |
| **GitHub Actions（`on: schedule`）** | GitHub のワークフローを定期実行する。サーバーが不要で設定が簡単 |
| **Celery Beat** | Django と組み合わせる非同期タスクスケジューラ。複雑なバッチ管理に向く |

## 12-2 Djangoのカスタム管理コマンド

### 管理コマンドとは何か

Chapter 4 で説明した `python manage.py runserver` や `python manage.py migrate` は、Django が標準で用意している**管理コマンド**です。同じ仕組みで、自分で独自のコマンドを作ることができます。これを**カスタム管理コマンド**と呼びます。

作成したコマンドは `python manage.py コマンド名` で実行できます。

### `management/commands/` ディレクトリの構造

カスタム管理コマンドは、アプリディレクトリの中に `management/commands/` というディレクトリを作り、そこにPythonファイルを置きます。

```
library/
├── management/                      ← 新規作成
│   ├── __init__.py                  ← Pythonパッケージとして認識させるための空ファイル
│   └── commands/                    ← 新規作成
│       ├── __init__.py              ← 同上
│       └── update_overdue_loans.py  ← コマンドの実装ファイル
```

`__init__.py` は中身が空のファイルです。「このディレクトリはPythonのパッケージ（モジュールの集まり）です」とPythonに伝えるために必要です。

### 🛠️ カスタム管理コマンドの雛形を作る

ディレクトリと `__init__.py` を作成します。

```bash
mkdir -p backend/library/management/commands
touch backend/library/management/__init__.py
touch backend/library/management/commands/__init__.py
```

`backend/library/management/commands/update_overdue_loans.py` を新規作成します。

```python
from django.core.management.base import BaseCommand  # カスタムコマンドの基底クラス


class Command(BaseCommand):  # クラス名は必ず Command にする
    help = '返却期限を過ぎた貸出のステータスを overdue に更新する'  # コマンドの説明

    def handle(self, *args, **options):  # handle メソッドにコマンドの処理を書く
        self.stdout.write('実行中...')  # self.stdout.write でコンソールに出力する
```

以下のコマンドを実行して「実行中...」と表示されれば、Django がコマンドを認識できています。

```bash
python manage.py update_overdue_loans
```

## 12-3 延滞ステータス更新バッチの実装

### バッチの仕様

今回実装するバッチの動作を整理します。

- **対象**：`status` が `active`（貸出中）かつ `due_date`（返却期限）が今日より前の貸出レコード
- **処理**：該当レコードの `status` を `overdue`（延滞）に更新する
- **実行タイミング**：毎日深夜（cron や GitHub Actions のスケジュール実行で定期実行する）

### 🛠️ `Loan` モデルに `overdue` ステータスを追加してマイグレーションする

現在の `Loan` モデルの `status` フィールドには `active`・`returned` の2種類があります。`overdue` を追加します。

`backend/library/models.py` の `Loan` モデルを編集します。

```python
class Loan(models.Model):
    STATUS_CHOICES = [
        ('active', '貸出中'),
        ('returned', '返却済み'),
        ('overdue', '延滞中'),  # 追加する
    ]
```

マイグレーションを実行します。

```bash
python manage.py makemigrations
python manage.py migrate
```

### 🛠️ 延滞ステータス更新コマンドを実装する

`backend/library/management/commands/update_overdue_loans.py` を以下のように実装します。

```python
from django.core.management.base import BaseCommand
from django.utils import timezone  # タイムゾーンを考慮した日時操作
from library.models import Loan


class Command(BaseCommand):
    help = '返却期限を過ぎた貸出のステータスを overdue に更新する'

    def handle(self, *args, **options):
        today = timezone.now().date()  # 今日の日付を取得する

        updated_count = Loan.objects.filter(
            status='active',     # 貸出中のレコードのみ対象にする
            due_date__lt=today,  # due_date__lt は「due_date が today より前」を意味する（lt = less than）
        ).update(status='overdue')  # 条件に一致するレコードをまとめて更新する

        self.stdout.write(
            self.style.SUCCESS(f'{updated_count}件の貸出を延滞ステータスに更新しました')
            # self.style.SUCCESS で緑色のテキストとして出力する
        )
```

`Loan.objects.filter(...).update(...)` は、条件に一致するレコードを1回のSQL文でまとめて更新します。1件ずつ `save()` を呼ぶよりも高速で、バッチ処理に適した書き方です。

### 🛠️ コマンドを実行して動作確認する

まず Django シェルで、返却期限切れの貸出データを作成します。

```bash
python manage.py shell
```

```python
from django.utils import timezone
from datetime import timedelta  # timedelta は日数・時間などの「時間の差」を表すクラス
from library.models import Loan, Book
from django.contrib.auth.models import User

user = User.objects.first()
book = Book.objects.first()

# 返却期限を3日前に設定した貸出レコードを作成する
Loan.objects.create(
    user=user,
    book=book,
    due_date=timezone.now().date() - timedelta(days=3),
    status='active',
)
exit()
```

バッチコマンドを実行します。

```bash
python manage.py update_overdue_loans
```

```
1件の貸出を延滞ステータスに更新しました
```

Django シェルで結果を確認します。

```bash
python manage.py shell
```

```python
from library.models import Loan
print(Loan.objects.filter(status='overdue').count())  # 1
exit()
```

`1` と表示されれば完成です。
