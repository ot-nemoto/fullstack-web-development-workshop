# Chapter 10：認証

この章では、ログイン・ログアウト機能を実装します。バックエンドにJWT認証を追加し、フロントエンドでログイン状態を管理し、未ログインユーザーをログインページにリダイレクトします。

## 10-1 認証の概念

### 認証と認可の違い

**認証**（Authentication）は「誰であるか」を確認することです。ユーザー名とパスワードでログインする操作が認証です。

**認可**（Authorization）は「何ができるか」を制御することです。「ログインしているユーザーだけが本を登録できる」「管理者だけが削除できる」といった制御が認可です。

本書では認証を実装します。認可の詳細なロールベースアクセス制御（RBAC）については触れませんが、Chapter 11の貸出機能で「自分の貸出データだけを見せる」という基本的な認可も実装します。

### セッションベース認証とトークンベース認証の違い

**セッションベース認証**は、ログイン後にサーバーがセッションIDを発行し、ブラウザがCookieで保持します。リクエストのたびにサーバーがセッションIDを照合します。サーバー側にセッション情報を保持するため、スケールアウトが難しい面があります。

**トークンベース認証（JWT）**は、ログイン後にサーバーがトークンを発行し、クライアントが保持します。以降のリクエストでトークンをヘッダーに付けて送ります。サーバーはトークンを検証するだけでよく、状態を保持しません。

本書では**JWT**（JSON Web Token）を使います。フロントエンドとバックエンドが分離したシステムと相性が良いためです。

### JWTの仕組み

JWTは3つの部分がドット（`.`）でつながった文字列です。

```
eyJhbGciOiJIUzI1NiJ9.eyJ1c2VyX2lkIjoxfQ.abc123
      ↑ヘッダー            ↑ペイロード      ↑署名
```

- **ヘッダー**：アルゴリズムの種類等のメタ情報
- **ペイロード**：ユーザーIDや有効期限などのデータ（Base64エンコードされているだけで暗号化はされていないため、秘密情報は入れない）
- **署名**：SECRET_KEYを使ったハッシュ値。改ざんを検出するために使う

トークンには**アクセストークン**（有効期間が短い・APIリクエストに使う）と**リフレッシュトークン**（有効期間が長い・アクセストークンを更新するために使う）の2種類があります。


### 🛠️ 認証が必要なエンドポイントにPermissionを設定する

本の登録・更新・削除はログインユーザーのみ許可します。`backend/library/views.py` に `permission_classes` を追加します。

```python
from rest_framework import viewsets, permissions  # permissionsを追加する
from .models import Book, Category, Loan
from .serializers import BookSerializer, CategorySerializer, LoanSerializer


class CategoryViewSet(viewsets.ModelViewSet):
    queryset = Category.objects.all()
    serializer_class = CategorySerializer
    permission_classes = [permissions.IsAuthenticatedOrReadOnly]
    # IsAuthenticatedOrReadOnly: GETは誰でも可、POST/PUT/DELETEはログイン必須


class BookViewSet(viewsets.ModelViewSet):
    queryset = Book.objects.all()
    serializer_class = BookSerializer
    permission_classes = [permissions.IsAuthenticatedOrReadOnly]


class LoanViewSet(viewsets.ModelViewSet):
    queryset = Loan.objects.all()
    serializer_class = LoanSerializer
    permission_classes = [permissions.IsAuthenticated]
    # IsAuthenticated: すべての操作にログイン必須
```

## 10-3 フロントエンドの認証実装

### 🛠️ ログインページを実装する

`frontend/src/app/login/page.tsx` を作成します。

```tsx
'use client'

import { useState } from 'react'
import { useRouter } from 'next/navigation'
import { useAuth } from '@/contexts/AuthContext'

export default function LoginPage() {
    const router = useRouter()
    const { login } = useAuth()
    const [username, setUsername] = useState('')
    const [password, setPassword] = useState('')
    const [error, setError] = useState('')
    const [isLoading, setIsLoading] = useState(false)

            await login(username, password)
            router.push('/books')
        } catch {
            setError('ユーザー名またはパスワードが正しくありません')
        } finally {
            setIsLoading(false)
        }
    }

    return (
        <main className="container mx-auto p-8 max-w-md">
            <h1 className="text-2xl font-bold mb-6">ログイン</h1>
            <form onSubmit={handleSubmit} className="space-y-4">
                {error && <p className="text-red-500">{error}</p>}
                <div>
                    <label className="block text-sm font-medium mb-1">ユーザー名</label>
                    <input
                        type="text"
                        value={username}
                        onChange={(e) => setUsername(e.target.value)}
                        className="w-full border rounded px-3 py-2"
                        required
                    />
                </div>
                <div>
                    <label className="block text-sm font-medium mb-1">パスワード</label>
                    <input
                        type="password"
                        value={password}
                        onChange={(e) => setPassword(e.target.value)}
                        className="w-full border rounded px-3 py-2"
                        required
                    />
                </div>
                <button
                    type="submit"
                    disabled={isLoading}
                    className="w-full py-2 bg-blue-500 text-white rounded hover:bg-blue-600 disabled:opacity-50"
                >
                    {isLoading ? 'ログイン中...' : 'ログイン'}
                </button>
            </form>
        </main>
    )
}
```

### 🛠️ トークンを保存・管理する

`frontend/src/lib/api.ts` にログイン関数を追加します。

```typescript
export async function loginUser(username: string, password: string) {
    const res = await fetch(`${API_URL}/api/token/`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ username, password }),
    })
    if (!res.ok) {
        throw new Error('ログインに失敗しました')
    }
    const data = await res.json()
    // localStorageはブラウザにデータを保存する仕組み（タブを閉じても残る）
    localStorage.setItem('access_token', data.access)
    localStorage.setItem('refresh_token', data.refresh)
    return data
}

export function getAccessToken(): string | null {
    return localStorage.getItem('access_token')
}

export function logoutUser() {
    localStorage.removeItem('access_token')
    localStorage.removeItem('refresh_token')
}
```

> **注意**：本書ではシンプルさのために `localStorage` を使いますが、実際のサービスでは XSS（クロスサイトスクリプティング）攻撃によってトークンが盗まれるリスクがあります。本番環境では JavaScript からアクセスできない httpOnly Cookie によるトークン管理が推奨されます。

認証が必要なリクエストにはトークンをヘッダーに付けます。`api.ts` のリクエスト関数を拡張します。

```typescript
// 認証ヘッダーを返すヘルパー関数
function authHeaders(): HeadersInit {
    const token = getAccessToken()
    return token
        ? { 'Content-Type': 'application/json', Authorization: `Bearer ${token}` }
        : { 'Content-Type': 'application/json' }
}

export async function createBook(data: Omit<Book, 'id'>): Promise<Book> {
    const res = await fetch(`${API_URL}/api/books/`, {
        method: 'POST',
        headers: authHeaders(),  // 認証ヘッダーを付ける
        body: JSON.stringify(data),
    })
    if (!res.ok) {
        throw new Error(`APIエラー: ${res.status}`)
    }
    return res.json()
}

export async function updateBook(id: number, data: Partial<Book>): Promise<Book> {
    const res = await fetch(`${API_URL}/api/books/${id}/`, {
        method: 'PUT',
        headers: authHeaders(),
        body: JSON.stringify(data),
    })
    if (!res.ok) {
        throw new Error(`APIエラー: ${res.status}`)
    }
    return res.json()
}

export async function deleteBook(id: number): Promise<void> {
    const res = await fetch(`${API_URL}/api/books/${id}/`, {
        method: 'DELETE',
        headers: authHeaders(),
    })
    if (!res.ok) {
        throw new Error(`APIエラー: ${res.status}`)
    }
}
```

### 🛠️ 認証状態をコンテキストで管理する

**Context**（コンテキスト）はReactの仕組みで、コンポーネントツリー全体に値を共有できます。ログイン状態をContextで管理すると、どのコンポーネントからでも「今ログインしているか」を確認できます。

`frontend/src/contexts/AuthContext.tsx` を作成します。

```tsx
'use client'

import { createContext, useContext, useState, useEffect, ReactNode } from 'react'
// createContext: コンテキストを作成する
// useContext: コンテキストの値を読み取る
// ReactNode: Reactコンポーネントを受け取る型
import { loginUser, logoutUser, getAccessToken } from '@/lib/api'

interface AuthContextType {
    isLoggedIn: boolean
    login: (username: string, password: string) => Promise<void>
    logout: () => void
}

const AuthContext = createContext<AuthContextType | null>(null)

export function AuthProvider({ children }: { children: ReactNode }) {
    const [isLoggedIn, setIsLoggedIn] = useState(false)

    useEffect(() => {
        // useEffect: コンポーネントのマウント時に実行される処理を定義する
        // ページ読み込み時にトークンが存在するかチェックする
        setIsLoggedIn(!!getAccessToken())  // !! は値をboolean に変換する
    }, [])  // [] は依存配列：空の場合はマウント時のみ実行される

    async function login(username: string, password: string) {
        await loginUser(username, password)
        setIsLoggedIn(true)
    }

    function logout() {
        logoutUser()
        setIsLoggedIn(false)
    }

    return (
        <AuthContext.Provider value={{ isLoggedIn, login, logout }}>
            {children}
        </AuthContext.Provider>
    )
}

export function useAuth(): AuthContextType {
    const context = useContext(AuthContext)
    if (!context) {
        throw new Error('useAuth は AuthProvider の内側で使ってください')
    }
    return context
}
```

`frontend/src/app/layout.tsx` で `AuthProvider` を全ページに適用します。

```tsx

}

                <AuthProvider>
                    {children}

        </html>
    )
}
```

## 10-4 ルート保護

### 🛠️ 未ログインユーザーをリダイレクトする

`frontend/src/components/RequireAuth.tsx` を作成します。

```tsx
'use client'

import { useEffect } from 'react'
import { useRouter } from 'next/navigation'
import { useAuth } from '@/contexts/AuthContext'

export default function RequireAuth({ children }: { children: React.ReactNode }) {
    const { isLoggedIn } = useAuth()
    const router = useRouter()

    useEffect(() => {
        if (!isLoggedIn) {
            router.push('/login')
        }
    }, [isLoggedIn, router])

    if (!isLoggedIn) {
        return <p>リダイレクト中...</p>
    }

    return <>{children}</>  // <>...</> はフラグメント：余分なDOM要素を作らずに複数要素をまとめる
}
```

### 🛠️ 認証済みユーザーのみアクセス可能なページを設定する

本の登録・編集ページを `RequireAuth` で保護します。

```tsx
import { useState, useEffect } from 'react'
import { getCategories, createBook } from '@/lib/api'
```

編集ページも同様に保護します。`edit/page.tsx` も `new/page.tsx` と同じく Client Component として実装します。

`frontend/src/app/books/[id]/edit/page.tsx` を以下のように書き換えます。

```tsx
'use client'

import { useState, useEffect } from 'react'
import { useParams } from 'next/navigation'
import { getBook, getCategories, updateBook } from '@/lib/api'
import BookForm from '@/components/BookForm'
import RequireAuth from '@/components/RequireAuth'
import { Book, Category } from '@/types'

export default function EditBookPage() {
    const params = useParams()
    const id = Number(params.id)
    const [book, setBook] = useState<Book | null>(null)
    const [categories, setCategories] = useState<Category[]>([])

    useEffect(() => {
        Promise.all([getBook(id), getCategories()]).then(([b, c]) => {
            setBook(b)
            setCategories(c)
        })
    }, [id])

    if (!book) return <p className="container mx-auto p-8">読み込み中...</p>

    return (
        <RequireAuth>
            <main className="container mx-auto p-8 max-w-2xl">
                <h1 className="text-2xl font-bold mb-6">本の編集</h1>
                <BookForm
                    initialData={book}
                    categories={categories}
                    onSubmit={async (data) => { await updateBook(id, data) }}
                    submitLabel="更新する"
                />
            </main>
        </RequireAuth>
    )
}
```

`'use client'` を宣言することで、このコンポーネントはブラウザで実行されます。`useParams()` でURLの `id` を取得し、`useEffect` でAPIからデータを取得します。`onSubmit` にクロージャ `async (data) => { await updateBook(id, data) }` を渡せるのは、同じクライアント側のコードであるためです。`async/await` でラップすることで、`BookForm` が期待する `Promise<void>` の型に合わせています。
